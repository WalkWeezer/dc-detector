# 🔄 Программный переворот и поворот изображения

Система поддерживает программный переворот и поворот изображения с камеры через переменные окружения.

## 📋 Доступные трансформации

### 1. Горизонтальный переворот (зеркало)

Переворачивает изображение по горизонтали (слева направо).

**Переменная окружения:**
```bash
FLIP_HORIZONTAL=true
```

**Или:**
```bash
FLIP_HORIZONTAL=1
FLIP_HORIZONTAL=yes
```

### 2. Вертикальный переворот

Переворачивает изображение по вертикали (сверху вниз).

**Переменная окружения:**
```bash
FLIP_VERTICAL=true
```

### 3. Поворот на угол

Поворачивает изображение на заданный угол (90°, 180° или 270°).

**Переменная окружения:**
```bash
ROTATE_ANGLE=180
```

**Доступные значения:** `0`, `90`, `180`, `270`

## 🚀 Использование

### Через переменные окружения

Добавьте в `.env` файл или установите перед запуском:

```bash
# Горизонтальный переворот
export FLIP_HORIZONTAL=true

# Вертикальный переворот
export FLIP_VERTICAL=true

# Поворот на 180 градусов
export ROTATE_ANGLE=180
```

### В systemd service

Добавьте в `systemd/dc-detection.service`:

```ini
[Service]
Environment="FLIP_HORIZONTAL=true"
Environment="FLIP_VERTICAL=false"
Environment="ROTATE_ANGLE=0"
```

### Комбинирование трансформаций

Можно комбинировать несколько трансформаций. Порядок применения:
1. Сначала поворот (ROTATE_ANGLE)
2. Затем горизонтальный переворот (FLIP_HORIZONTAL)
3. Затем вертикальный переворот (FLIP_VERTICAL)

**Пример:** Перевернуть камеру, установленную вверх ногами:
```bash
export ROTATE_ANGLE=180
```

**Пример:** Зеркальное отображение (для фронтальной камеры):
```bash
export FLIP_HORIZONTAL=true
```

**Пример:** Камера установлена боком (поворот на 90°):
```bash
export ROTATE_ANGLE=90
```

## 🔍 Проверка

После установки переменных окружения перезапустите detection service:

```bash
# Остановка
sudo systemctl stop dc-detection

# Запуск
sudo systemctl start dc-detection

# Проверка логов
sudo journalctl -u dc-detection -f
```

Откройте видеопоток в браузере и проверьте, что изображение перевернуто/повернуто правильно.

## ⚙️ Технические детали

- Трансформации применяются ко всем кадрам автоматически
- Обработка выполняется через OpenCV (`cv2.flip()` и `cv2.rotate()`)
- Трансформации применяются после захвата кадра, но до детекции
- Не влияет на производительность (минимальные накладные расходы)

## 📝 Примеры использования

### Камера установлена вверх ногами:
```bash
export ROTATE_ANGLE=180
```

### Фронтальная камера (зеркало):
```bash
export FLIP_HORIZONTAL=true
```

### Камера установлена боком (90° по часовой):
```bash
export ROTATE_ANGLE=90
```

### Камера установлена боком (90° против часовой):
```bash
export ROTATE_ANGLE=270
```

### Комбинация: поворот + зеркало:
```bash
export ROTATE_ANGLE=90
export FLIP_HORIZONTAL=true
```
