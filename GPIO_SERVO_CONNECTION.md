# 🔌 Подключение двух микросерв через GPIO на Raspberry Pi

## 📌 Рекомендуемые GPIO пины

Для двух микросерв рекомендуется использовать следующие GPIO пины:

### Вариант 1 (Рекомендуется):
- **Pan серво** (горизонтальное вращение): **GPIO 18** (физический пин 12)
- **Tilt серво** (вертикальное вращение): **GPIO 19** (физический пин 35)

### Вариант 2 (Альтернатива):
- **Pan серво**: **GPIO 13** (физический пин 33)
- **Tilt серво**: **GPIO 12** (физический пин 32)

## 🔌 Схема подключения

### Подключение Pan серво (GPIO 18):

```
Микросерва Pan:
├── Красный провод (VCC)  → 5V (физический пин 2 или 4)
├── Коричневый/Черный (GND) → GND (физический пин 6, 9, 14, 20, 25, 30, 34, 39)
└── Оранжевый/Желтый (Signal) → GPIO 18 (физический пин 12)
```

### Подключение Tilt серво (GPIO 19):

```
Микросерва Tilt:
├── Красный провод (VCC)  → 5V (физический пин 2 или 4)
├── Коричневый/Черный (GND) → GND (физический пин 6, 9, 14, 20, 25, 30, 34, 39)
└── Оранжевый/Желтый (Signal) → GPIO 19 (физический пин 35)
```

## 📍 Распиновка Raspberry Pi (40-pin)

```
    3.3V  [1]  [2]  5V
   GPIO2  [3]  [4]  5V
   GPIO3  [5]  [6]  GND
   GPIO4  [7]  [8]  GPIO14
     GND  [9] [10]  GPIO15
  GPIO17 [11] [12]  GPIO18  ← Pan серво (Signal)
  GPIO27 [13] [14]  GND
  GPIO22 [15] [16]  GPIO23
    3.3V [17] [18]  GPIO24
  GPIO10 [19] [20]  GND
   GPIO9  [21] [22]  GPIO25
  GPIO11 [23] [24]  GPIO8
     GND [25] [26]  GPIO7
   GPIO0 [27] [28]  GPIO1
   GPIO5 [29] [30]  GND
   GPIO6 [31] [32]  GPIO12
  GPIO13 [33] [34]  GND
  GPIO19 [35] [36]  GPIO16  ← Tilt серво (Signal)
  GPIO26 [37] [38]  GPIO20
     GND [39] [40]  GPIO21
```

## ⚡ Питание

**ВАЖНО:** Микросервы потребляют много тока (до 1А каждая при нагрузке). 

### Вариант A: Питание от Raspberry Pi (для тестирования)
- Можно использовать 5V пины Raspberry Pi (пин 2 или 4)
- **Ограничение:** Raspberry Pi может обеспечить только ~1.5А через USB
- Подходит только для легких сервоприводов без нагрузки

### Вариант B: Внешнее питание (рекомендуется)
- Используйте внешний блок питания 5V (минимум 2-3А)
- Подключите:
  - **+5V** внешнего блока → красные провода обеих серв
  - **GND** внешнего блока → GND Raspberry Pi (общая земля!)
  - **Signal** → GPIO пины (18 и 19)

**⚠️ КРИТИЧНО:** Всегда соединяйте GND внешнего питания с GND Raspberry Pi!

## 🛠️ Настройка системы

### 1. Установите библиотеку RPi.GPIO:

```bash
pip install RPi.GPIO
```

Или в виртуальном окружении проекта:
```bash
cd services/detection
source ../../venv/bin/activate
pip install RPi.GPIO
```

### 2. Настройте переменные окружения:

Создайте или отредактируйте файл `.env` в корне проекта:

```bash
# Настройки сервоприводов
SERVO_HARDWARE=gpio
SERVO_PAN_PIN=18
SERVO_TILT_PIN=19
SERVO_FREQUENCY=50
```

Или установите через systemd service (`systemd/dc-detection.service`):

```ini
[Service]
Environment="SERVO_HARDWARE=gpio"
Environment="SERVO_PAN_PIN=18"
Environment="SERVO_TILT_PIN=19"
Environment="SERVO_FREQUENCY=50"
```

### 3. Проверьте подключение:

Перед запуском проверьте, что провода подключены правильно:
- ✅ Красный → 5V
- ✅ Черный/коричневый → GND
- ✅ Оранжевый/желтый → GPIO 18 (Pan) и GPIO 19 (Tilt)

## ⚠️ Важные замечания

1. **Питание:** Если сервоприводы дергаются или не работают - проблема в питании. Используйте внешний блок питания.

2. **GPIO пины:** GPIO 18 и 19 поддерживают hardware PWM, что обеспечивает плавную работу. Другие пины будут использовать software PWM (менее плавно).

3. **Защита:** При неправильном подключении можно повредить Raspberry Pi. Всегда проверяйте подключение перед включением питания.

4. **GND обязателен:** Без общего GND между внешним питанием и Raspberry Pi сервоприводы не будут работать правильно.

## 🐛 Устранение неполадок

**Сервоприводы не двигаются:**
- Проверьте подключение проводов
- Убедитесь, что установлен RPi.GPIO: `pip list | grep RPi.GPIO`
- Проверьте логи на ошибки инициализации
- Проверьте питание (используйте мультиметр)

**Сервоприводы дергаются:**
- Недостаточно питания - используйте внешний блок питания 5V 2-3А
- Проверьте, что GND соединен правильно

**Ошибка "RPi.GPIO not available":**
- Убедитесь, что код запускается на Raspberry Pi (не на Windows/PC)
- Установите библиотеку: `pip install RPi.GPIO`

**Сервоприводы двигаются в неправильную сторону:**
- Это нормально, можно инвертировать в коде или поменять местами pan/tilt

## 📝 Пример полной схемы подключения

```
                    Raspberry Pi
                        │
        ┌───────────────┼───────────────┐
        │               │               │
     [Pin 2]         [Pin 12]       [Pin 35]
      5V          GPIO 18 (Pan)  GPIO 19 (Tilt)
        │               │               │
        │               │               │
     [Pin 6]            │               │
      GND               │               │
        │               │               │
        └───────┬───────┴───────┬───────┘
                │               │
            Pan Servo      Tilt Servo
         (Красный→5V)    (Красный→5V)
         (Черный→GND)    (Черный→GND)
         (Желтый→GPIO18) (Желтый→GPIO19)
```

**С внешним питанием:**
```
Внешний блок 5V 3A
    │
    ├── +5V ──┬──→ Pan Servo (красный)
    │         └──→ Tilt Servo (красный)
    │
    └── GND ──┬──→ Raspberry Pi GND (pin 6)
              └──→ Pan Servo (черный)
              └──→ Tilt Servo (черный)

Raspberry Pi:
    GPIO 18 → Pan Servo (желтый)
    GPIO 19 → Tilt Servo (желтый)
```
